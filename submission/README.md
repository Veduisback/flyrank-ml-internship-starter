## Project

**Research question:**
Can historical content-performance signals be used to prioritize which content items should receive human SEO/editorial review?

**Approach:**
A research-stage logistic regression model uses historical search-performance signals to rank content items for human review. The model is evaluated against a staleness-and-search-demand baseline using grouped client validation.

**Intended use:**
The resulting ranking is a decision-support tool for prioritizing human SEO/editorial review. It is not an automated content-refresh system and does not establish causal effects of refreshing content.
